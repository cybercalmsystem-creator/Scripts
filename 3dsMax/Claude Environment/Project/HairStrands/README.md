# Hair Strands — пряди волос (hair cards) по поверхности модели

Автор: Гриб Виктор (Games, 3D). Сделано с Claude. Вопросы и отзывы — Виктору.

| Файл | Программа |
|---|---|
| `HairStrands.ms` | 3ds Max 2027 |
| `Blender/hair_strands_blender.py` | Blender 4.2+ / 5.x |

## 3ds Max

1. Scripting → Run Script… → `HairStrands.ms`.
2. После первого запуска есть команда Customize → категория **Hair Tools** → «Hair Strands» (на панель или горячую клавишу).
3. «Выбрать модель» → «Рисовать пряди»: зажать ЛКМ и вести по модели. ПКМ / Esc — выход.
4. Или нарисовать Line / Freehand и нажать «Из выделенных сплайнов».

## Blender

1. Edit → Preferences → Add-ons → Install from Disk… → `hair_strands_blender.py`.
2. 3D View → N-панель → вкладка **Hair Strands**.
3. Единицы — метры, значения по умолчанию — для головы 20–25 см.

## Что умеет

- Ширина, корень и кончик, выпуклость, отступ, толщина, слои, разброс — меняются на лету.
- Живое обновление: правишь вершины направляющей — прядь перестраивается сама.
- У каждой пряди своя ровная UV 0–1 (V — по длине, U — по ширине).
- Общий материал `HairStrands_Mat`: Albedo с альфой и Normal (tangent space, переключатель DirectX G).
- «Объединить всё» — один меш для экспорта.
