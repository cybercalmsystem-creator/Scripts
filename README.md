# Scripts

Скрипты, созданные в работе над проектами (Unity, 3ds Max, пайплайн ассетов).

## Структура

| Папка | Что лежит |
|---|---|
| `Unity/` | C#-скрипты для Unity (runtime и Editor) |
| `3dsMax/` | MAXScript (`.ms`) и Python для 3ds Max |
| `PowerShell/` | `.ps1`-утилиты и автоматизация |
| `Python/` | Отдельные Python-скрипты |

Внутри папки скрипты сгруппированы по проекту-источнику, например `Unity/3D-Assistant/`.
